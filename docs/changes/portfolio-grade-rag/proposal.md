# 将 RAG 原型升级为可演示作品

## 背景
当前项目具备基础上传、检索与流式问答能力，但存在模型与数据库配置硬编码、服务启动即加载本地模型、上传状态不可靠、接口契约不一致等问题，难以作为可复现的工程项目展示。

## 目标
- 将模型、存储、数据库与 CORS 配置移至环境变量，移除仓库中的真实凭据。
- 以延迟初始化和健康检查让没有本地模型的开发环境仍可启动、检查与演示 UI。
- 提供可追溯的混合检索问答、结构化上传状态与文档清单接口。
- 增加多轮 Query Rewrite、Parent-Child Retrieval、结构化 Citation Validator 与可公开的 Retrieval Trace，形成从问题理解到回答校验的完整链路。
- 自建版本化标注问题集和固定 corpus，比较 Vector、BM25、RRF、Rerank 的 Recall@K、MRR、nDCG@K，并记录真实降级而不是虚构成绩。
- 将 Vue 前端重构为面向知识库问答、索引链路和离线评测的响应式工作台，并使用同源 `/api` 代理。
- 补全数据库初始化、配置模板、评测 API、架构说明、录制脚本与简历表述。

## 非目标
- 本次不把答案语义正确性伪装成检索指标；评测范围是检索排序和引用结构，不做自动事实裁判。
- 不改变现有单节点向量库或改造为多租户服务；多实例任务持久化仍是部署阶段工作。

## 验收标准
- `python -m compileall` 通过，前端 production build 通过。
- 未配置本地模型时，应用导入和 `/health` 逻辑不触发模型加载。
- 所有机密值来自环境变量，不写入版本库。
- 问答返回来源元数据，上传任务公开 `queued/processing/completed/failed` 生命周期。
- 多轮追问可降级为原问题检索；父子 chunk 可在重启后恢复；SSE 返回引用完整性校验事件。
