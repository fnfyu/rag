# ADR 0002：知识库拥有版本化资料，任务保存不可变报告快照

- 状态：采用
- 背景：V1 把会话与资料集合视为同一对象，同名上传替换来源；V2 需要共享资料、多任务续接和解释报告受到资料演进的影响。

## 决策

1. 知识库拥有唯一 Chroma 集合，多个会话和研究任务引用知识库，不复制索引。
2. 资料系列组织同名资料；资料版本拥有独立 `source_id`、文件快照、标签、发布日期和适用条件。上传先后不是有效性排序规则。
3. 研究任务保存可编辑提纲、研究范围及逐章 checkpoint；不可变报告版本保留完整正文、证据和核验快照。
4. 报告版本与任务当前报告在一个 PostgreSQL 事务内保存；恢复操作新增快照。范围内的来源编号只追加，不重新编号未改章节。
5. 使用现有 PostgreSQL 而非另引入 SQLite 或第二套元数据源。数据库脚本完成可重复迁移，旧集合、来源 ID 和消息不变。

## 结果和边界

- 可以共享资料、引用旧版本、局部修订及追溯历史，而不会因重新上传或改一章破坏旧引用。
- 现有安装需要先运行 [迁移脚本](<../../scripts/init_db.sql>)，不是只替换后端文件。
- 保留旧会话中的 `collection_name` 列用于兼容，但检索从知识库解析；不允许该旧列重新成为资料所有权的真相来源。
- 章节 checkpoint 持久化，执行器仍是单服务进程后台任务。服务重启后用户显式续接；分布式任务调度留给独立部署需求，不冒充已具备的工作队列。
- 图像描述和表格计算保留派生证据类型，不与资料原始文字混淆。
